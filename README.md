# Roblox-Minesweeper
  2D Minesweeper in Roblox
  
  And yet again another system.
  To setup the system all you need to do is:
  1. Downolad .rbxm file from Release
  2. Paste it in Baseplate/Your Place in Roblox Studio
  3. Place it in ScreenGui in StarterGui
  4. Press Play
  5. Done

  You can customize GridSize/Mine Amount.
